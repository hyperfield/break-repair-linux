# Roadmap

Near-term directions for this repository:

- add real RH-compatible scenarios in the highest-value categories first
- add real RH-compatible setup/verification tasks in parallel
- tag scenarios by difficulty, topic, and exam relevance
- tag tasks by difficulty, topic, and exam relevance
- add linting for shell scripts and scenario metadata
- support non-RHEL families under the same scenario contract
- add optional wrappers to launch a scenario and capture logs
- split public hints from private instructor notes if needed
